IPlugin

Every plugin has one class that implements IPlugin. It's how Melon finds your plugin, tells you about itself, and starts and stops it. The Getting Started tutorial walks through a full one. 

public interface IPlugin
{
    // About your plugin
    string Name { get; }
    string Version { get; }
    string Authors { get; }       // separate more than one with commas
    string Description { get; }

    // Filled in by Melon when it loads you
    IHost Host { get; set; }
    IWebApi WebApi { get; set; }
    void LoadMelonCommands(IHost host);
    void LoadMelonServerCommands(IWebApi webapi);

    // Start and stop. Return 0 when it worked.
    int Execute();
    int Destroy();

    // Launch arguments you read, shown in MelonWebApi --help
    Dictionary<string, string> GetHelpOptions();

    // Old, kept so older plugins still load. You don't need these.
    int LoadUI() => 0;
    int UnloadUI() => 0;
}

What Each One Is For

MemberWhat it's for
Name, AuthorsShown in the plugin list. Together they're your plugin's id, so keep the pair unique.
VersionYour plugin's version, like 1.0.0.
DescriptionOne line about what it does.
LoadMelonCommandsCalled first, with IHost. Save it to Host.
LoadMelonServerCommandsCalled next, with IWebApi. Save it to WebApi.
ExecuteCalled when your plugin starts. Register middleware, hook events, start timers. Anything but 0 means it failed to start.
DestroyCalled when it's disabled, reloaded, or Melon stops. Undo everything Execute did.
GetHelpOptionsYour launch arguments and what they do. Read them from Host.StateManager.LaunchArgs.

IControllerPlugin

Implement this as well to get a page in MelonGUI and MelonCLI. See Controller Page. 

public interface IControllerPlugin
{
    PluginPage GetPage();                                // the fields and buttons
    object? Invoke(string action, JsonElement values);   // a button was pressed
}

public record PluginPage(PluginField[] Fields, PluginAction[] Actions);
public record PluginField(string Key, string Label, string Type, object Value);
public record PluginAction(string Key, string Label);
