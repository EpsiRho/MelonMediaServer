IHost

IHost is everything Melon lets your plugin use: the library, settings, scans, admin tools and artwork. Melon gives it to you in LoadMelonCommands, and you use it through Host.

The Interface

public interface IHost
{
    string Version { get; }
    IMelonAPI MelonAPI { get; }
    IStorageAPI Storage { get; }
    IMelonScanner MelonScanner { get; }
    IStateManager StateManager { get; }
    IMelonAdministration Administration { get; }
    IArtworkProviderRegistry Artwork { get; }
}

Version

  • Type: string
  • Description: The version of the plugin interface, so you can check what this Melon supports.

IMelonAPI

Library helpers.

public interface IMelonAPI
{
    List<Track> ShuffleTracks(List<Track> tracks, string UserId, ShuffleType type, bool fullRandom = false, bool enableTrackLinks = true);
}
  • ShuffleTracks: Shuffles tracks using one of Melon's shuffle modes. Set enableTrackLinks to keep linked tracks together.

IStorageAPI

Loads and saves configuration files in Melon's Configs folder.

public interface IStorageAPI
{
    T LoadConfigFile<T>(string filename, string[] protectedProperties, out bool converted);
    void SaveConfigFile<T>(string filename, T config, string[] protectedProperties);
}
  • protectedProperties: Property names to encrypt in the saved file.
  • converted: True when the file was upgraded while loading.

See Managing Settings.

IMelonScanner

Reads scan progress and starts scans.

public interface IMelonScanner
{
    string CurrentFolder { get; }
    string CurrentFile { get; }
    string CurrentStatus { get; }
    double ScannedFiles { get; }
    double FoundFiles { get; }
    long averageMilliseconds { get; }
    bool Indexed { get; }
    bool Scanning { get; }

    void StartScan(bool skip);
    void UpdateCollections();
    void ResetDB();
}
  • StartScan(skip): true runs a short scan that skips unchanged files.
  • UpdateCollections(): Refreshes every collection's tracks.
  • ResetDB(): Clears the library database. Use with care.

See Melon Scanner.

IStateManager

Melon's current state and settings.

public interface IStateManager
{
    string melonPath { get; }
    ShortSettings MelonSettings { get; }
    Flags MelonFlags { get; }
    ResourceManager StringsManager { get; }
    List<IPlugin> Plugins { get; }
    Dictionary<string, string> LaunchArgs { get; }
    byte[] GetDefaultImage();
}
  • melonPath: Melon's data folder.
  • MelonSettings: A read-only view of Settings.
  • MelonFlags: See Flags.
  • LaunchArgs: Arguments Melon was started with, without leading dashes.
  • GetDefaultImage(): The placeholder image used for missing artwork.

Administration

IMelonAdministration is the same set of operations MelonGUI and MelonCLI use: status, settings, scans, users, invites, backups, updates, plugins, artwork, and visuals. Calls run in the server process. 

var status = Host.Administration.GetStatus();
Host.Administration.SetQueueCleanupHours(48);

See Local Controllers for how these are grouped.

Artwork

Register an IArtworkProvider to add a source of artist pictures and banners. Admins enable, order, and give API keys to providers from the controllers. Melon asks enabled providers in priority order and keeps the first image found for each kind. 

public interface IArtworkProviderRegistry
{
    void Register(IArtworkProvider provider);
    bool Unregister(string id);
    IReadOnlyList<IArtworkProvider> Providers { get; }
}

public interface IArtworkProvider
{
    string Id { get; }                       // stable, lowercase, e.g. "deezer"
    string Name { get; }
    string Description { get; }
    IReadOnlyCollection<ArtworkKind> Kinds { get; }   // ArtistPicture, ArtistBanner
    bool RequiresApiKey => false;
    string? ApiKeyUrl => null;
    bool RequiresMusicBrainzId => false;
    bool EnabledByDefault => false;

    Task<IReadOnlyList<ArtworkCandidate>> FindArtistArtworkAsync(
        ArtworkQuery query, ArtworkProviderContext context, CancellationToken cancellation);
}
public int Execute()  { Host.Artwork.Register(new MyProvider()); return 0; }
public int Destroy()  { Host.Artwork.Unregister("my-provider"); return 0; }
  • Return an empty list when nothing matches confidently. A wrong image is worse than none.
  • Throw UnauthorizedAccessException when the API key is rejected.
  • Use context.Http. It already sends Melon's User-Agent; don't dispose it.
  • Providers own their rate limiting.

See Artwork.
