Account Management APIs Documentation

These endpoints let admins manage accounts, invites, and password resets from a client. They match the account tools in MelonGUI and MelonCLI. A reset code lasts ten minutes, can be used once, and replaces any earlier code for that account. Changing the password invalidates the account's login tokens.

Summary of Endpoints

Endpoint Method Description Authorization
/api/users/manage GET Lists every account. Admin
/api/users/{id}/password-reset-code POST Issues a reset code for a user. Admin
/auth/reset-password POST Sets a new password with a reset code. None
/auth/invites GET Lists open invite codes. Admin
/auth/invites/revoke POST Cancels an invite code. Admin
/api/stats/summary GET Server or per-user listening summary. Admin

List Users

Returns every account's ID, name, and role.

Details:

  • Endpoint: /api/users/manage
  • Method: GET
  • Authorization: JWT (Roles: Admin)

Responses:

  • 200 OK: A list of users.

Example Request:

curl -X GET "https://your-api-url.com/api/users/manage" \
     -H "Authorization: Bearer <JWT-token>"

Create Password Reset Code

Creates a single-use, ten-minute reset code. Give it to the user, who enters it at /auth/reset-password on your server.

Details:

  • Endpoint: /api/users/{id}/password-reset-code
  • Method: POST
  • Authorization: JWT (Roles: Admin)

Parameters:

  • id (string, required): The user's ID (in the path).

Responses:

  • 200 OK: The reset code.
  • 404 Not Found: If the user is not found.

Example Request:

curl -X POST "https://your-api-url.com/api/users/66bc99b8ab7ba419497e21af/password-reset-code" \
     -H "Authorization: Bearer <JWT-token>"

Reset Password

Completes a reset. Opening this address with GET shows a simple reset form. Requests are rate limited per address.

Details:

  • Endpoint: /auth/reset-password
  • Method: POST
  • Authorization: None

Parameters:

  • body (JSON, required): { "code": "...", "password": "..." }

Responses:

  • 204 No Content: If the password was changed.
  • 400 Bad Request: If the code is invalid or expired, or the password is rejected.

Example Request:

curl -X POST "https://your-api-url.com/auth/reset-password" \
     -H "Content-Type: application/json" \
     -d '{"code":"ABCD1234","password":"new password"}'

List Invites

Returns the invite codes that haven't been used or revoked.

Details:

  • Endpoint: /auth/invites
  • Method: GET
  • Authorization: JWT (Roles: Admin)

Responses:

  • 200 OK: A list of invites.

Example Request:

curl -X GET "https://your-api-url.com/auth/invites" \
     -H "Authorization: Bearer <JWT-token>"

Revoke Invite

Revokes an invite so it can no longer be used to sign up.

Details:

  • Endpoint: /auth/invites/revoke
  • Method: POST
  • Authorization: JWT (Roles: Admin)

Parameters:

  • body (JSON string, required): The invite code.

Responses:

  • 204 No Content: If the invite was revoked.

Example Request:

curl -X POST "https://your-api-url.com/auth/invites/revoke" \
     -H "Authorization: Bearer <JWT-token>" \
     -H "Content-Type: application/json" \
     -d '"ABCD1234"'

Listening Summary

Returns a listening summary for the last few days, for the whole server or one user.

Details:

  • Endpoint: /api/stats/summary
  • Method: GET
  • Authorization: JWT (Roles: Admin)

Parameters:

  • userId (string, optional): Limit the summary to one user. Leave empty for everyone.
  • days (int, optional): How many days back to look. Defaults to 7.

Responses:

  • 200 OK: The summary.
  • 400 Bad Request: If the user or day count is invalid.

Example Request:

curl -X GET "https://your-api-url.com/api/stats/summary?days=30" \
     -H "Authorization: Bearer <JWT-token>"
