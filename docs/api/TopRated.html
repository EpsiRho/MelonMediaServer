Top Rated APIs Documentation

The TopRatedController ranks tracks, albums, and artists server-wide by their average rating across users. Only ratings clients are allowed to see count: those from users with public stats, plus your own. Unrated items are left out, and each item's Ratings holds exactly the ratings its average was taken over.

Controller Route: /api/top-rated

All routes within the TopRatedController are prefixed by /api/top-rated.

Summary of Endpoints

Endpoint Method Description Authorization
/api/top-rated/tracks GET Tracks by average rating. Admin, User, Pass
/api/top-rated/albums GET Albums by average rating. Admin, User, Pass
/api/top-rated/artists GET Artists by average rating. Admin, User, Pass

Top Rated Tracks

Returns tracks sorted by their average rating, highest first.

Details:

  • Endpoint: /api/top-rated/tracks
  • Method: GET
  • Authorization: JWT (Roles: Admin, User, Pass)

Parameters:

  • page (int, optional): The page to return. Defaults to 0.
  • count (int, optional): Items per page, 1 to 500. Defaults to 50.
  • minRatings (int, optional): Leave out items rated by fewer users than this. Defaults to 1.

Responses:

  • 200 OK: A list of ResponseTrack objects.
  • 400 Bad Request: If the page is negative.

Example Request:

curl -X GET "https://your-api-url.com/api/top-rated/tracks?page=0&count=50&minRatings=2" \
     -H "Authorization: Bearer <JWT-token>"
