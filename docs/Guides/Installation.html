Installation

Prerequisites

Installing Melon is super easy, and releases come with everything they need to run, so you don't need .NET installed. The one thing you need is a database.

  • Melon stores your library in MongoDB.
    • On Windows, MelonGUI's setup can install a dedicated, password protected MongoDB service for you. You can also point it at one you already run.
    • On Linux and macOS, install MongoDB first by following the MongoDB Linux Installation Docs or the MongoDB macOS Installation Docs.

Install Melon

  • Head to the Download page and click Install Latest. This grabs the MelonInstaller for your system.
  • Run the installer. It will ask which branch you want (if there is more than one) and where to install, then download and extract the latest release on that branch.
    • Prefer to skip the questions? Pass them in: 
      MelonInstaller -branch Beta -installPath "C:\Melon"
    • Already downloaded a release zip? Install it with -localPath <zip>.
  • When it finishes, the installer opens a controller for you:
    • Opened by double-clicking: MelonGUI opens.
    • Run from a terminal: MelonCLI starts in that same terminal.
    • Add -noLaunch to skip this.

What's Installed

FolderWhat it is
ServerMelonWebApi, the server itself.
ControllerMelonGUI, the Windows app for setup and administration. Windows only.
CLIMelonCLI, the terminal app for setup and administration.
InstallerMelonInstaller, used for updates and switching branches.

The default install folder is %LocalAppData%\MelonInstall on Windows and ~/.local/share/MelonInstall on Linux.

First Time Setup

  • MelonGUI or MelonCLI will start the server and walk you through setup.
    • Here you'll set up your Admin account's Username and Password, link Melon to your MongoDB instance, and link to the folders you store your music files in.
  • Start a scan as soon as possible, as no songs will be available in your library until a scan has completed.
    • You have the choice between Full and Short scan, but for a first scan they will both end up being full scans. This is because the short scan skips files that haven't been modified since last scan.

Installation is complete! But there are a few more things to configure.

Configuration

  • You may need to port forward to the PC/Server you're hosting Melon on. The port Melon uses by default is 14524, but you can change it by setting the listening URL in Networking settings.
  • HTTPS allows Melon to send traffic securely, and some clients / devices may require it.
    • To set up HTTPS, open Networking settings in MelonGUI or MelonCLI.
    • You'll need an SSL cert, which you can get through CertBot.
    • SSL Certs expire, but Melon will inform you if your cert is expired on startup, or when you visit the HTTPS settings.

See Configure for every setting.

Updating

Melon checks GitHub for newer releases on its branch. Update from MelonGUI, MelonCLI, or a client, or run the installer yourself: 

MelonInstaller -update -restart -installPath "C:\Melon"

To switch branches, run the installer with -branch. See Branches.
