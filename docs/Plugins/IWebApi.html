IWebApi

IWebApi is how a plugin gets into Melon's web API. You can add middleware, which runs before Melon handles a request and can answer it instead, or listen to events, which fire after Melon handled one. Custom Endpoints shows both.

A few endpoints don't have an event yet.

Middleware

MethodWhat it does
UsePluginMiddleware(new(name, func))Adds your middleware. name is just a label so you can remove it later. Returns false if that name is taken.
RemovePluginMiddleware(name)Removes it. Do this in Destroy.
GetPluginMiddlewares()Every middleware that's registered, from every plugin.

Your function gets a WebApiEventArgs for every signed-in request. Return bytes and that's the response. Return null and the request carries on to the next middleware, then to Melon.

Events

Each endpoint has an event that fires right before Melon sends its response. You get the same WebApiEventArgs, plus the StatusCode and Message Melon is answering with. Events can't change the response, they just tell you it happened. Remember to unhook them in Destroy.
