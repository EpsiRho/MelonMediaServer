Plugin Tutorial: Managing Settings

Most plugins need to remember something between restarts. Melon gives you Host.Storage for this: you make a class for your settings, and save or load the whole thing in one line. It's written to Configs/<name>.json in Melon's data folder, and any fields you mark as protected get encrypted.

1. Make a Settings Class

Any class that can be turned into JSON works:

public class MyPluginConfig
{
    public string GreetingMessage { get; set; } = "Hello from My First Plugin!";
    public bool Loud { get; set; }
}

2. Load and Save

public MyPluginConfig Config { get; set; }

private void LoadConfig()
{
    // Returns null the first time, before the file exists.
    Config = Host.Storage.LoadConfigFile<MyPluginConfig>("MyPluginConfig", null, out _);
    if (Config == null)
    {
        Config = new MyPluginConfig(); // defaults from the class
        SaveConfig();
    }
}

private void SaveConfig()
{
    Host.Storage.SaveConfigFile("MyPluginConfig", Config, null);
}

Load it as soon as you get Host, so your settings are ready before Execute runs: 

public void LoadMelonCommands(IHost host)
{
    Host = host;
    LoadConfig();
}

From then on just read Config wherever you need it.

3. Edit Them From Your Page

Put your settings on the page from the Controller Page tutorial, and save them when the button is pressed: 

public PluginPage GetPage() => new(
    [
        new("greeting", "Greeting message", "text", Config.GreetingMessage),
        new("loud", "Shout it", "boolean", Config.Loud),
    ],
    [new("save", "Save settings")]);

public object? Invoke(string action, JsonElement values)
{
    if (action != "save") throw new ArgumentException("Unknown action.");

    Config.GreetingMessage = values.GetProperty("greeting").GetString() ?? "";
    Config.Loud = values.GetProperty("loud").GetBoolean();
    SaveConfig();

    return GetPage(); // redraw the page with the saved values
}

4. Protect Secrets

Things like API keys shouldn't sit in a file as plain text. Pass their property names as protectedProperties and Melon encrypts them in the file and decrypts them when you load. Use the same list for both: 

string[] secret = ["ApiKey"];
Host.Storage.SaveConfigFile("MyPluginConfig", Config, secret);
Config = Host.Storage.LoadConfigFile<MyPluginConfig>("MyPluginConfig", secret, out _);

5. Notice Edits to the File

If someone edits the JSON file by hand while Melon is running, your plugin won't know unless it watches the file: 

// Keep this as a field. If it gets garbage collected, it stops watching.
private FileSystemWatcher watcher;

public int Execute()
{
    watcher = new FileSystemWatcher(Path.Combine(Host.StateManager.melonPath, "Configs"), "MyPluginConfig.json")
    {
        NotifyFilter = NotifyFilters.LastWrite | NotifyFilters.FileName,
    };
    watcher.Changed += (_, _) =>
    {
        // Ignore a half-written file, keep the old settings instead.
        var updated = Host.Storage.LoadConfigFile<MyPluginConfig>("MyPluginConfig", null, out _);
        if (updated != null) Config = updated;
    };
    watcher.EnableRaisingEvents = true;
    return 0;
}

public int Destroy()
{
    watcher?.Dispose();
    return 0;
}

6. Try It

Rebuild, copy the .dll into Plugins, and restart Melon. Change a setting on your plugin's page, press Save settings, then restart Melon again. Your setting should still be there, and Configs/MyPluginConfig.json should have it.
