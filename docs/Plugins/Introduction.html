Plugins

Plugins are how you add your own stuff to Melon without changing Melon itself. A plugin is just a C# class library (a .dll) with a class that implements IPlugin. Melon loads every .dll in its Plugins folder when it starts.

From a plugin you can:

  • Use Melon's own services through IHost: the library, settings, scans, users, artwork, and so on.
  • Add new API endpoints, or replace existing ones, through IWebApi.
  • Run code when an endpoint is called, through IWebApi's events.
  • Give yourself a page in MelonGUI and MelonCLI with settings and buttons.
  • Add a source of artist pictures and banners.

Installing a Plugin

Drop the plugin's .dll into the Plugins folder in Melon's data folder, then restart Melon. The data folder is %LocalAppData%\Melon on Windows and ~/.local/share/Melon on Linux. MelonGUI and MelonCLI both have a button that opens it for you.

Make sure the plugin was built for your version of Melon. A plugin built against an older MelonLib.dll may fail to load, and Melon logs why.

Making Plugins

The tutorials build one plugin step by step. Start with Getting Started and go in order:

  1. Getting Started: make the project and a plugin Melon loads.
  2. Controller Page: give it a page in MelonGUI and MelonCLI.
  3. Managing Settings: save and load its settings.
  4. Custom Endpoints: add your own API endpoints.

The interface pages (IPlugin, IHost, IWebApi) list everything available.
