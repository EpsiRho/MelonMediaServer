Plugin Tutorial: Managing Settings

Most plugins will need to save and load settings. Melon provides IStorageAPI for this purpose. It allows you to define an object as your settings class and save/load it in one line, along with built in security with encrypted fields. This saves the object to the Melon/Configs folder as <name>.json.

Step-by-Step Guide

1. Create a Configuration Class

Define a class to hold your plugin's settings. This can support any values json supports. 


    public class MyPluginConfig
    {
        public string GreetingMessage { get; set; }
        public bool EnableFeatureX { get; set; }
    }

2. Load and Save Settings Using IStorageAPI

a. Load Settings


    public MyPluginConfig Config { get; set; }
    private void LoadConfig()
    {
        Config = Host.Storage.LoadConfigFile<MyPluginConfig>("MyPluginConfig", null, out bool converted);
        if (Config == null)
        {
            Config = new MyPluginConfig
            {
                GreetingMessage = "Hello from My First Plugin!",
                EnableFeatureX = true
            };
            Host.Storage.SaveConfigFile("MyPluginConfig", Config, null);
        }
    }

b. Save Settings


    private void SaveConfig()
    {
        Host.Storage.SaveConfigFile("MyPluginConfig", Config, null);
    }

3. Use Settings in Your Plugin

Read Config wherever your plugin needs it, for example in a middleware or an action:

var greeting = Config.GreetingMessage;

4. Edit Settings From a Controller Page

Show your settings as fields on your controller page, and save them when the Save action is pressed: 

public PluginPage GetPage() => new(
    [
        new("greeting", "Greeting message", "text", Config.GreetingMessage),
        new("featureX", "Enable feature X", "boolean", Config.EnableFeatureX),
    ],
    [new("save", "Save settings")]);

public object? Invoke(string action, JsonElement values)
{
    if (action != "save") throw new ArgumentException("Unknown action.");
    Config = new MyPluginConfig
    {
        GreetingMessage = values.GetProperty("greeting").GetString() ?? "",
        EnableFeatureX = values.GetProperty("featureX").GetBoolean()
    };
    SaveConfig();
    return GetPage(); // redraw with the saved values
}

5. Protect Secrets

Pass property names in protectedProperties to encrypt them in the saved file, such as API keys: 

Host.Storage.SaveConfigFile("MyPluginConfig", Config, ["ApiKey"]);
Config = Host.Storage.LoadConfigFile<MyPluginConfig>("MyPluginConfig", ["ApiKey"], out _);

6. Initialize Config

Ensure you load the config when the plugin is initialized. Melon calls both of these when your plugin loads, so loading in both is safe. 


    public void LoadMelonCommands(IHost host)
    {
        Host = host;
        LoadConfig();
    }
    public void LoadMelonServerCommands(IWebApi webapi)
    {
        WebApi = webapi;
        LoadConfig();
    }

7. Watching for changes

When someone edits the config file with a text editor, the server wont have a way to know the config has changed unless you tell it. 


    watcher = new FileSystemWatcher();
    watcher.Path = $"{Host.StateManager.melonPath}/Configs/";
    
    watcher.NotifyFilter = NotifyFilters.LastWrite
                            | NotifyFilters.FileName
                            | NotifyFilters.DirectoryName;
    
    watcher.Filter = "*.json";
    
    FileSystemEventHandler func = (sender, args) =>
    {
        if(args.Name == "MyPluginConfig.json")
        {
            var temp = Host.Storage.LoadConfigFile<MyPluginConfig>("MyPluginConfig", null, out _);
            if (temp != null) Config = temp;
        }
    };
    
    // Add event handlers.
    watcher.Changed += func;
    watcher.Created += func;
    
    watcher.EnableRaisingEvents = true;

Make sure to make the watcher variable global, if it is disposed it will stop watching.

8. Rebuild and Test

  • Rebuild your plugin.
  • Copy the DLL to Melon's Plugins directory.
  • Restart Melon.
  • Open your plugin in MelonGUI or MelonCLI, change a setting, and press Save settings.
  • Verify changes take effect in your plugin.
