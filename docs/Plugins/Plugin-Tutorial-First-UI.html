Plugin Tutorial: Controller Page

In this tutorial, we'll give your plugin a page in Melon's controllers. You describe the page once, as fields and actions, and both MelonGUI and MelonCLI draw it for you. When someone presses an action, Melon calls your plugin on the server with the values they entered.

This tutorial continues from Getting Started.

Step-by-Step Guide

1. Implement IControllerPlugin

Add IControllerPlugin next to IPlugin:

public class MyFirstPlugin : IPlugin, IControllerPlugin
{
    // ... IPlugin members from Getting Started ...

    public PluginPage GetPage() => new(
        [
            new("name", "Your name", "text", "Melon"),
            new("loud", "Shout it", "boolean", false),
        ],
        [
            new("greet", "Say hello"),
        ]);

    public object? Invoke(string action, JsonElement values)
    {
        if (action != "greet") throw new ArgumentException("Unknown action.");
        var name = values.GetProperty("name").GetString();
        var text = $"Hello, {name}!";
        return values.GetProperty("loud").GetBoolean() ? text.ToUpper() : text;
    }
}

2. Understanding the Code

  • GetPage returns a PluginPage(PluginField[] Fields, PluginAction[] Actions).
  • PluginField: (Key, Label, Type, Value). The key is how you read the value back, the label is what people see, and the value is what the field starts with.
  • PluginAction: (Key, Label), shown as a button.
  • Invoke gets the pressed action's key and every field's current value as JSON, keyed by field key.
    • Return a string to show a message.
    • Return a new PluginPage to redraw the page.
    • Throw an ArgumentException to show an error.

3. Rebuild and Test

  • Rebuild your plugin and copy the .dll into Melon's Plugins folder.
  • Restart Melon.
  • Open MelonGUI or MelonCLI, go to Plugins, and select your plugin.
  • Press Say hello.

4. Add Help Options

Launch arguments your plugin reads are listed by MelonWebApi --help. Add them in GetHelpOptions: 

public Dictionary<string, string> GetHelpOptions() => new()
{
    { "--resetMyPlugin", "Resets My First Plugin's settings." }
};

Read them in Execute through Host.StateManager.LaunchArgs.

5. Extra Considerations

  • Pages are drawn from your field list, so keep pages short and save anything long-running for Execute.
  • Invoke runs on the server, not in the controller. It can use everything in Host, including Host.Administration.
  • The page only shows while your plugin is enabled.
