User Pictures APIs Documentation

Users can set a profile picture. Users change their own picture, and admins can replace anyone's for moderation. Pictures are re-encoded on the server.

Summary of Endpoints

Endpoint Method Description Authorization
/api/art/upload/user-pfp POST Sets a profile picture. Admin, User
/api/art/delete/user-pfp POST Removes a profile picture. Admin, User
/api/download/user-pfp GET Gets a profile picture. Admin, User, Pass

Upload User Picture

Uploads a PNG or JPEG as a user's profile picture.

Details:

  • Endpoint: /api/art/upload/user-pfp
  • Method: POST
  • Authorization: JWT (Roles: Admin, User)

Parameters:

  • id (string, optional): The user to change. Leave it out to change your own.
  • image (form file, required): The picture.

Responses:

  • 200 OK: If the picture was saved.
  • 400 Bad Request: If the file isn't a usable image.
  • 403 Forbidden: If a non-admin tries to change someone else's picture.
  • 404 Not Found: If the user doesn't exist.

Example Request:

curl -X POST "https://your-api-url.com/api/art/upload/user-pfp" \
     -H "Authorization: Bearer <JWT-token>" \
     -F "image=@me.png"

Delete User Picture

Removes a user's profile picture.

Details:

  • Endpoint: /api/art/delete/user-pfp
  • Method: POST
  • Authorization: JWT (Roles: Admin, User)

Parameters:

  • id (string, optional): The user to change. Leave it out to change your own.

Responses:

  • 200 OK: If the picture was removed.
  • 403 Forbidden: If a non-admin tries to change someone else's picture.
  • 404 Not Found: If the user doesn't exist.

Example Request:

curl -X POST "https://your-api-url.com/api/art/delete/user-pfp" \
     -H "Authorization: Bearer <JWT-token>"

Download User Picture

Returns a user's profile picture. A user with no picture returns 404, so clients can draw their own placeholder, such as initials.

Details:

  • Endpoint: /api/download/user-pfp
  • Method: GET
  • Authorization: JWT (Roles: Admin, User, Pass)

Parameters:

  • id (string, required): The user's ID.
  • size (int, optional): Resize to this many pixels wide. 0 returns the stored size.

Responses:

  • 200 OK: The image.
  • 404 Not Found: If the user has no picture.

Example Request:

curl -X GET "https://your-api-url.com/api/download/user-pfp?id=66bc99b8ab7ba419497e21af&size=256" \
     -H "Authorization: Bearer <JWT-token>" -o pfp.jpg
