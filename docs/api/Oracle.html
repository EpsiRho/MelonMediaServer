Oracle Mixes APIs Documentation

Oracle Mixes are the server's pick of the day or month. The pick comes from the server's local date, so everyone on the server sees the same mix regardless of their time zone or device. A theme genre is drawn first, then tracks from it, and a small library is topped up from all tracks. The same day always gives the same mix, and adding tracks only changes it slightly.

Controller Route: /api/oracle

All routes within the OracleController are prefixed by /api/oracle.

Summary of Endpoints

Endpoint Method Description Authorization
/api/oracle/daily GET Today's Oracle Mix. Admin, User, Pass
/api/oracle/monthly GET This month's Oracle Mix. Admin, User, Pass

Daily Mix

Returns today's mix.

Details:

  • Endpoint: /api/oracle/daily
  • Method: GET
  • Authorization: JWT (Roles: Admin, User, Pass)

Parameters:

  • count (int, optional): Number of tracks, 1 to 200. Defaults to 50.

Responses:

  • 200 OK: An object with period ("daily"), date (yyyy-MM-dd), genre (the drawn genre, or null), refreshesAt (UTC), and tracks.

Example Request:

curl -X GET "https://your-api-url.com/api/oracle/daily?count=50" \
     -H "Authorization: Bearer <JWT-token>"

Monthly Mix

Returns this month's mix.

Details:

  • Endpoint: /api/oracle/monthly
  • Method: GET
  • Authorization: JWT (Roles: Admin, User, Pass)

Parameters:

  • count (int, optional): Number of tracks, 1 to 200. Defaults to 50.

Responses:

  • 200 OK: The same shape as the daily mix, with period "monthly" and date as yyyy-MM.

Example Request:

curl -X GET "https://your-api-url.com/api/oracle/monthly" \
     -H "Authorization: Bearer <JWT-token>"
