EqController Documentation

EQ filters are saved equalizers that the server applies to a track before sending it. Each filter belongs to the user who made it. The owner can make it public, and then any user can pick it. Only the owner can edit a filter. The owner or an admin can delete it. When a user is deleted, their filters go with them.

In lists, show each filter's name and ownerName. To play a track through a filter, add eq=<filter id> to /api/download/track (an equalized WAV that starts at once and supports Range) or /api/download/track-transcode (MP3, cached per filter version).

How it sounds

Filters are processed by Nova's Equalizer. Every band uses matched second-order filters, which keep their analog shape all the way up the spectrum. A cookbook (bilinear) EQ squeezes high bells and shelves against Nyquist, so a 16 kHz bell on a 44.1 kHz track gets narrower and loses its top. Processing is in double precision, so narrow bass bands stay clean. With autoHeadroom on (the default), the output is lowered by the curve's highest boost, so boosting doesn't clip. Anything that still goes above −1 dBFS is soft-clipped rather than hard-clipped. Ten bands cost about 1–2 ms of CPU per second of stereo audio, far less than decoding.

Controller Route: /api/eq

All routes are prefixed by /api/eq/ and need a JWT with the Admin or User role.

FieldMeaning
name1–100 characters.
preampOutput gain in dB, −30 to 30, applied after the bands.
autoHeadroomLower the output by the curve's highest boost (default true). Turn off to set the level yourself with preamp.
bandsUp to 32, applied in order.
bands[].typepeak, lowShelf, highShelf, lowPass, highPass, bandPass or notch (case-insensitive; stored in this spelling).
bands[].frequencyCentre or corner in Hz, 10–40,000. Values at or near a track's Nyquist frequency are pulled just under it. A low-pass above it is skipped.
bands[].gainBoost or cut in dB, −30 to 30. Used by peak and the shelves.
bands[].q0.05–40; higher is narrower. Peak, band-pass and notch: 1.41 is about one octave wide. Shelves: 0.707 is a smooth transition, and higher adds a bump. Low/high-pass at 12 dB/oct: resonance, where 0.707 is flat. Steeper slopes use a Butterworth response and ignore it.
bands[].slopeLow/high-pass roll-off: 6, 12, 18, 24, 36 or 48 dB per octave.
bands[].enabledDisabled bands are kept but not applied.

List

GET /api/eq/list returns the filters the user can pick: their own plus every public one, sorted by name.

  • mine (bool, optional): Only the user's own filters.
  • name (string, optional): Case-insensitive substring of the name.
  • page, count (int, optional): Paging. Count defaults to 100, max 500.
curl "https://your-melon-server.com/api/eq/list" -H "Authorization: Bearer <User-JWT>"

Get

GET /api/eq/get?id=… returns one filter. 404 if it doesn't exist, or if it's private and belongs to someone else.

Add

POST /api/eq/add with a JSON body of name, isPublic (optional, default false), preamp, autoHeadroom and bands. Returns the new ID as a JSON string. 400 with a message for invalid values, or when the user already has 200 filters.

curl -X POST "https://your-melon-server.com/api/eq/add" \
     -H "Authorization: Bearer <User-JWT>" -H "Content-Type: application/json" \
     -d '{ "name": "Vocal lift", "bands": [ { "type": "peak", "frequency": 2500, "gain": 3, "q": 1.2 } ] }'

Update

POST /api/eq/update?id=… with the same body as Add. It replaces the name, bands, preamp and headroom setting. isPublic changes visibility only when it's included. 404 if the filter isn't the user's.

Set Public

POST /api/eq/set-public?id=…&isPublic=true shows the filter to every user, or hides it again with false. Owner only.

Delete

DELETE /api/eq/delete?id=… (POST also works). Owners can delete their own filters, and admins can delete any.

Response Curve

GET /api/eq/response?id=… returns the curve of a saved filter, and POST /api/eq/response with an Add body returns the curve of unsaved settings. Use it to draw the curve while the user edits.

  • points (int, optional): Number of log-spaced frequencies from 20 Hz to 20 kHz, 2–4096 (default 256).
  • sampleRate (int, optional): The rate to design for (default 44100). The curve near Nyquist depends on it.
{ "frequencies": [20, 20.5, …, 20000], "gains": [-9.1, -8.4, …, 1.5], "outputGain": -3.2, "sampleRate": 44100 }

gains is the bands' combined response in dB. outputGain is the preamp minus the automatic headroom, applied to everything.
