Metadata Updates APIs Documentation

The UpdateController lets admins edit the stored metadata of tracks, albums, and artists. Send the whole object back with your changes.

Controller Route: /api/update

All routes within the UpdateController are prefixed by /api/update.

Summary of Endpoints

Endpoint Method Description Authorization
/api/update/track PUT Updates a track's metadata. Admin
/api/update/album PUT Updates an album's metadata. Admin
/api/update/artist PUT Updates an artist's metadata. Admin

Update Track

Replaces a track's editable metadata with the body you send.

Details:

  • Endpoint: /api/update/track
  • Method: PUT
  • Authorization: JWT (Roles: Admin)

Parameters:

  • id (string, required): The ID of the track.
  • body (ResponseTrack, required): The track with your changes.

Responses:

  • 200 OK: If the track was updated.
  • 400 Bad Request: If the id or body is missing.
  • 404 Not Found: If the track is not found.

Example Request:

curl -X PUT "https://your-api-url.com/api/update/track?id=66bc99b8ab7ba419497e21af" \
     -H "Authorization: Bearer <JWT-token>" \
     -H "Content-Type: application/json" \
     -d @track.json
